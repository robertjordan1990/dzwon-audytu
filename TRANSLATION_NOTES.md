# English reading editions — scope and source versions

The English editions are draft reading translations of Robert Jordan's dated Polish reports. They translate the selectable narrative, quotations, references and figure captions. Original document reproductions and screenshots remain in the linked Polish PDF; the translations identify their source pages. They do not recreate official documents in English or report later developments.

All three reading translations received an independent text comparison against their Polish source within the Codex review process. Layout checks covered all 25 English PDF pages. These are editorial checks, not a determination of the underlying disputes or a certified legal translation.

Part 1 has a file reference physically clipped at the right edge of source page 1. The English text marks that limitation instead of reconstructing the missing characters. The dated quoted funding code is retained as printed. Part 3's discussion of retention concerns preserving logs against retention-related loss or overwriting; it does not assert that a loss has already occurred.

Common terminology: *postanowienie* → **order**, *decyzja* → **decision**, RDN → **Council of Scientific Excellence (RDN)**, WSA → **Voivodeship Administrative Court**. Polish case references and institution abbreviations are retained.

The Polish PDF bytes and existing ZIP packages are unchanged. The catalogue and SHA-256 manifest identify the exact files. Materials outside the existing public archive are assessed separately before any addition.

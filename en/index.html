Purpose of this site

This is a static public archive. It provides an additional online location for source materials and publications.

The site has no login area, forms, comments, CMS, PHP or external analytics. Published files should have SHA-256 checksums.

The English pages describe the existing publications. Polish PDFs remain the source publications; draft English reading translations are provided for review.
